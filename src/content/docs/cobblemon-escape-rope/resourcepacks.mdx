Cobblemon Escape Rope includes some built-in resource packs for the Escape Rope item. These resource packs are automatically registered and can be used as-is or serve as templates for custom resource packs.

## Included Resource Packs

- **Legacy Item Model**: A resource pack that replaces the 3D model of the Escape Rope item with the legacy pre-1.2.0 Escape Rope model. This is useful for players who prefer the old look or for compatibility with older resource packs.


## Enabling/Disabling Resource Packs

The resource packs included with Cobblemon Escape rope are disabled by default, to enable them, go to the Resource packs menu in Minecraft and enable the desired resource pack(s) from the list.
