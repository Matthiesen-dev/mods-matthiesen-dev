The cooldown time and rewards can be configured in the mod's configuration file. This allows server owners to customize the
Pokestop experience to fit their server's needs. The configuration file can be found in the server's config directory after installing the mod.

- **Default config location:** `<game_directory>/config/cobblemon_pokestops/config.json`

## Default Configuration Example

```json title="<game_directory>/config/cobblemon_pokestops/config.json"
{
  "broadcastSettings": {
    "enableGlobalBroadcast": false,
    "localBroadcastRadius": 50.0
  },
  "cooldowns": {
    "pokestops": 300,
    "wingedstops": 300,
    "pokeballstops": 300,
    "healingstops": 600
  },
  "stopRemoverConfig": {
    "requireOp": false,
    "permissionLevel": 2,
    "dropsStopItem": false,
    "confirmWindowSeconds": 5
  },
  "extraRarities": [
    "cobblemon:master_ball",
    "cobblemon:ancient_origin_ball",
    "cobblemon:ability_capsule",
    "cobblemon:max_revive",
    "cobblemon:hyper_potion",
    "cobblemon:ultra_ball",
    "cobblemon:master_rod"
  ]
}
```

## Main Config options

- **`broadcastSettings`:** This section contains the configuration options for the broadcast settings of Pokestops.
  - **`enableGlobalBroadcast`:** Whether to enable global broadcast messages when a player interacts with a Pokestop. (Default: false)
  - **`localBroadcastRadius`:** The radius in blocks for local broadcast messages when a player interacts with a Pokestop. (Default: 50.0)
- **`cooldowns`:** This section contains the configuration options for the cooldown times of different types of Pokestops.
  - **`pokestops`:** The cooldown time in seconds for regular Pokestops. (Default: 300)
  - **`wingedstops`:** The cooldown time in seconds for WingedStops. (Default: 300)
  - **`pokeballstops`:** The cooldown time in seconds for Pokeball Stops. (Default: 300)
  - **`healingstops`:** The cooldown time in seconds for Healing Stops. (Default: 600)
- **`stopRemoverConfig`:** This section contains the configuration options for the Stop Remover item.
  - **`requireOp`:** Whether to require the player to be an operator to use the Stop Remover item. (Default: false)
  - **`permissionLevel`:** The permission level required to use the Stop Remover item. (Default: 2)
  - **`dropsStopItem`:** Whether the Stop Remover item drops the Pokestop item when used. (Default: false)
  - **`confirmWindowSeconds`:** The number of seconds the player has to confirm the use of the Stop Remover item. (Default: 5)
- **`extraRarities`:** This section contains a list of additional items that can be added to the Pokestop loot tables. These items will be added to the loot tables in addition to the default items. (Default: shown in the example above)
