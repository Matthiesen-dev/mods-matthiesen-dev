This mod adds compatibility for Cobblemon NPCs to interact with the LuckPerms Permissions API.

## Dependencies
- [Cobblemon 1.7.3+](https://modrinth.com/mod/cobblemon)
- [Luckperms 5.4](https://modrinth.com/mod/luckperms)
