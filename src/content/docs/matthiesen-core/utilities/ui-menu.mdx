## AbstractNoInventoryMenu

A simple menu that has no inventory. This is useful for GUIs that don't need to interact with the player's inventory, such as a crafting table or furnace GUI. This menu will not allow the player to move items in or out of the menu, and it will not have any slots. It can be used as a base class for GUIs that don't need an inventory,

```java
import dev.matthiesen.matthiesen_core.utility.ui.menu.AbstractNoInventoryMenu;

public class MyMenu extends AbstractNoInventoryMenu {
  public MyMenu(MenuType<?> menuType, int id) {
    super(menuType, id);
  }
}
```
