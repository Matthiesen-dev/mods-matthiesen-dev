Utility class for creating and opening menus. This is used to avoid having to duplicate menu creation and opening across platforms. It provides a method for creating a SimpleMenuProvider from a MenuConstructor and a title, and a method for opening a menu for a player using a SimpleMenuProvider.

:::note
The Following code snippet is the actual implementation of the MenuProvider class. And not a usable code snippet. It is provided for reference only.
:::

```java title="MenuProvider.java"
package dev.matthiesen.matthiesen_core.common.utility.ui.menu;

import net.minecraft.network.chat.Component;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.world.SimpleMenuProvider;
import net.minecraft.world.inventory.MenuConstructor;

public final class MenuProvider {
    public static SimpleMenuProvider createMenuProvider(MenuConstructor constructor, Component title) {
        return new SimpleMenuProvider(constructor, title);
    }

    public static void openMenuForPlayer(ServerPlayer player, SimpleMenuProvider menuProvider) {
        player.openMenu(menuProvider);
    }
}
```
