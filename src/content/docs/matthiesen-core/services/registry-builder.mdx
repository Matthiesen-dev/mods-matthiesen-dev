---
title: "Registry Builder"
description: "The RegistryBuilder class provides a convenient and standardized way for mod developers to register various game elements"
---

The RegistryBuilder class provides a convenient and standardized way for mod developers to register various game elements such as items, blocks, block entities, creative mode tabs, sound events, criteria triggers, statistics, menu types, data component types, enchantment entity effects, and features.

Getting a RegistryBuilder instance is simple and can be done using the static method `getBuilder(String modId)`, where `modId` is the unique identifier for your mod. This method returns a new instance of the RegistryBuilder class, which can then be used to register your game elements.

```java title="RegistryExample.java"
package com.example.registry;

import dev.matthiesen.matthiesen_core.common.core.registry.RegistryBuilder;

public class RegistryExample {
  public static RegistryBuilder getBuilder() {
    return new RegistryBuilder("example_mod");
  }
}
```

## Available Methods

- `getModId`: Returns the mod ID associated with this RegistryBuilder instance.
- `newCreativeTabBuilder`: Creates a new builder for a creative mode tab.
- `registerBlockEntity`: Registers a block entity type.
- `registerBlock`: Registers a block type.
- `registerItem`: Registers an item type.
- `registerSound`: Registers a sound event.
- `registerCriteriaTriggers`: Registers criteria triggers for advancements.
- `registerStats`: Registers custom statistics.
- `registerMenuType`: Registers a menu type for GUIs.
- `registerDataComponentType`: Registers a data component type.
- `registerEntityEffects`: Registers entity effects.
- `registerFeature`: Registers a feature for world generation.
- `registerCreativeModeTab`: Registers a creative mode tab.
