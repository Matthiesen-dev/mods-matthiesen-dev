All of the configuration files for Global Ban are located in the `<game_directory>/config/global_ban/` directory.

**Configuration files:**
- `server-config.toml` - This file contains the server-side configuration for Global Ban. You can use this file to change the default settings for the mod, such as the default level cap and scaling method.
- `permissions.toml` - This file contains the permission nodes for Global Ban. You can use this file to change the permission nodes for the commands and features of the mod.
- `punished-accounts.toml` - This file contains the list of accounts that have been punished by Global Ban. You can use this file to view and manage the punished accounts.

## Server Configuration

```toml title="server-config.toml"
[server]
	serverUUID = "d445bb2d-7054-4844-bc12-8e5eb5900788"
	autoBanPlayersByIP = false
	showKnownAccounts = false
	showPunishActionsInChat = false
	defaultBanReason = "Unknown reason"
	textParser = "VANILLA"
	[server.scheduler]
		cpuCorePoolSize = 1

		apiSyncEnabled = false
		apiSyncInterval = 30
```

### serverUUID

The UUID of the server. This is used to identify the server when syncing punishments between servers. If you want to reset your server's UUID, delete this config and restart the server.

- Type: `string`
- Default: randomly generated UUID

### autoBanPlayersByIP

Whether to automatically ban alt accounts by IP address when a player is banned.

- Type: `boolean`
- Default: `true`

### showKnownAccounts

Whether to show known accounts for a player when they join the server.

- Type: `boolean`
- Default: `false`

### showPunishActionsInChat

Whether to show punish actions publicly in chat.

- Type: `boolean`
- Default: `false`

### defaultBanReason

The default reason to use when banning a player without a reason.

- Type: `string`
- Default: `Unknown reason`

### textParser

The text parser to use for parsing text. This can be used to change the way text is displayed in chat and on the disconnect screen.

- Type: `enum`
- Allowed Values: `VANILLA`, `EMBERS`, `ADVENTURE`
- Default: `VANILLA`

### Scheduler Config

#### cpuCorePoolSize

The number of CPU cores to use for the scheduler. This can be used to improve performance on servers with multiple CPU cores.

- Type: `integer`
- Default: `1`

#### expiredPunishmentsCheckInterval

The interval in minutes to check for and process expired punishments. This can be used to reduce the load on the server by checking for expired punishments less frequently.

- Type: `integer`
- Default: `5`

#### apiSyncEnabled

Whether to enable syncing of punishments to a remote API. This requires a compatible API to be set up.

- Type: `boolean`
- Default: `false`

#### apiSyncInterval

The interval in minutes to sync punishments to the remote API. This can be used to reduce the load on the server by syncing punishments less frequently.

- Type: `integer`
- Default: `30`

#### apiSyncUrl

The URL of the remote API to sync punishments with. This is required if `apiSyncEnabled` is set to `true`.

- Type: `string`
- Default: `""`

## Punished Accounts

```toml title="punished-accounts.toml"
accounts = []
accounts_pending_sync = []
```

### accounts

List of punished accounts. Each entry is a serialized [PunishmentRecord](#punishmentrecord) object.

### accounts_pending_sync

List of punished accounts that are pending sync. Each entry is a serialized [PunishmentRecord](#punishmentrecord) object.

## Types

### PunishmentRecord

A PunishmentRecord object represents a record of a punished account.

#### Fields

- `type` - The type of punishment (e.g. ban, mute, kick).
- `timestamp` - The timestamp of when the punishment was issued.
- `duration` - The duration of the punishment (in seconds). A value of `-1` indicates a permanent punishment.
- `playerUuid` - The UUID of the punished player.
- `playerDisplayName` - The display name of the punished player.
- `punisherUuid` - The UUID of the player who issued the punishment.
- `punisherDisplayName` - The display name of the player who issued the punishment.
- `reason` - The reason for the punishment.
- `serverUuid` - The UUID of the server where the punishment was issued.

### PermissionLevel

A PermissionLevel object represents a level of permission that can be assigned to a player.

#### Allowed Values

- `NONE` - No permissions.
- `SPAWN_PROTECTION_BYPASS` - Can bypass spawn protection.
- `CHEAT_COMMANDS_AND_COMMAND_BLOCKS` - Can use cheat commands and command blocks.
- `MULTIPLAYER_MANAGEMENT` - Can manage multiplayer settings.
- `ALL_COMMANDS` - Can use all commands.
