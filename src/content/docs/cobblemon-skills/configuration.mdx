All of the configuration files for Cobblemon Skills are located in the `<game_directory>/config/cobblemon_skills/` directory.

**Configuration files:**
- `permissions.toml` - This file contains the configuration related to Command and GUI permissions.
- `server.toml` - This file contains the configuration related to server settings.
- `professions/<profession>.toml` - This file contains the configuration related to each profession, including rewards and experience gained.

## Permissions Configuration

```toml title="permissions.toml"
[permissions]
	[permissions.command]
		cobbleskills = "NONE"
		cobbleskills_reset = "NONE"
		cobbleskills_reset_self = "NONE"
		cobbleskills_reset_player = "MULTIPLAYER_MANAGEMENT"
		cobbleskills_reset_all = "ALL_COMMANDS"
		cobbleskills_leaderboard = "NONE"
		cobbleskills_profile = "NONE"
		cobbleskills_profession = "NONE"
		cobbleskills_admin = "ALL_COMMANDS"
		cobbleskills_admin_add_exp = "ALL_COMMANDS"
		cobbleskills_admin_set_level = "ALL_COMMANDS"
		cobbleskills_admin_reload = "ALL_COMMANDS"
	[permissions.gui]
		main_menu = "NONE"
		leaderboard = "NONE"
		profile = "NONE"
		profile_other = "NONE"

```

### Permissions Configuration

Allowed Values:
- `NONE` - No one can use this command.
- `SPAWN_PROTECTION_BYPASS` - Only players with spawn protection bypass can use this command.
- `CHEAT_COMMANDS_AND_COMMAND_BLOCKS` - Only players with cheat commands and command blocks can use this command.
- `MULTIPLAYER_MANAGEMENT` - Only players with multiplayer management permissions can use this command.
- `ALL_COMMANDS` - All players can use this command.

#### command permissions

Permissions for accessing the commands of Cobblemon Skills.

##### cobbleskills

The permission level required to use the `/cobbleskills` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_reset

The permission level required to use the `/cobbleskills reset` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_reset_self

The permission level required to use the `/cobbleskills reset self` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_reset_player

The permission level required to use the `/cobbleskills reset player` command.

- Type: `enum`
- Default: `MULTIPLAYER_MANAGEMENT`

##### cobbleskills_reset_all

The permission level required to use the `/cobbleskills reset all` command.

- Type: `enum`
- Default: `ALL_COMMANDS`

##### cobbleskills_leaderboard

The permission level required to use the `/cobbleskills leaderboard` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_profile

The permission level required to use the `/cobbleskills profile` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_profession

The permission level required to use the `/cobbleskills profession` command.

- Type: `enum`
- Default: `NONE`

##### cobbleskills_admin

The permission level required to use the `/cobbleskills admin` command.

- Type: `enum`
- Default: `ALL_COMMANDS`

##### cobbleskills_admin_add_exp

The permission level required to use the `/cobbleskills admin addExp` command.

- Type: `enum`
- Default: `ALL_COMMANDS`

##### cobbleskills_admin_set_level

The permission level required to use the `/cobbleskills admin setLevel` command.

- Type: `enum`
- Default: `ALL_COMMANDS`

##### cobbleskills_admin_reload

The permission level required to use the `/cobbleskills admin reload` command.

- Type: `enum`
- Default: `ALL_COMMANDS`

#### GUI permissions

Permissions for accessing the GUI components of Cobblemon Skills.

##### main_menu

The permission level required to access the main menu GUI.

- Type: `enum`
- Default: `NONE`

##### leaderboard

The permission level required to access the leaderboard GUI.

- Type: `enum`
- Default: `NONE`

##### profile

The permission level required to access the profile GUI.

- Type: `enum`
- Default: `NONE`

##### profile_other

The permission level required to access another player's profile GUI.

- Type: `enum`
- Default: `NONE`

## Server Configuration

```toml title="server.toml"
#Server configuration for Cobblemon Skills
[server]
	#Maximum level for all professions
	# Default: 100
	# Range: > 1
	professionMaxLevel = 100
	#Base experience required for each level
	# Default: 1020
	# Range: > 1
	professionBaseExpPerLevel = 1020
	#Multiplier for experience required per level
	# Default: 20
	# Range: > 1
	professionExpLevelMultiplier = 20
```

### professionMaxLevel

The maximum level for all professions.

- Type: `integer`
- Default: `100`
- Range: `> 1`

### professionBaseExpPerLevel

The base experience required for each level.

- Type: `integer`
- Default: `1020`
- Range: `> 1`

### professionExpLevelMultiplier

The multiplier for experience required per level.

- Type: `integer`
- Default: `20`
- Range: `> 1`

### Profession Configuration

Each Profession configuration file contains the following sections:

#### professionName

The name of the profession.

- Type: `string`

#### Experience Settings

Experience settings for the profession, including base experience gained from various actions and bonuses for specific conditions.

#### Rewards Settings

Rewards settings for the profession, including whether extra drops are randomly applied to block breaking rewards, the minimum level required for extra drops, and the chance for extra drops to be applied.

#### Profession Rewards Tiers

These Rewards are available from the reward claim GUI, and are unlocked when the player reaches the required level for that tier. Each tier can have multiple rewards.

There is three types of rewards that can be configured for each profession: `EXPERIENCE`, `ITEM`, and `COMMAND`.

Experience rewards have the following configuration options:
- `type` - The type of reward. Must be set to `EXPERIENCE`.
- `experience` - The amount of experience to reward the player.

Item rewards have the following configuration options:
- `type` - The type of reward. Must be set to `ITEM`.
- `item` - The item to reward the player. Must be a valid Minecraft item ID.
- `amount` - The amount of the item to reward the player.

Command rewards have the following configuration options:
- `type` - The type of reward. Must be set to `COMMAND`.
- `command` - The command to execute when the player reaches the required level. 

> Note: The command will be executed as the server console, and can include the placeholder `{player}` to represent the player's username.
