All of the configuration files for Cobblemon Skills are located in the `<game_directory>/config/cobblemon_skills/` directory.

**Configuration files:**
- `permissions.toml` - This file contains the configuration related to Command and GUI permissions.
- `server.toml` - This file contains the configuration related to server settings.
- `text.toml` - This file contains the configuration related to text and messages displayed by the mod.
- `professions/<profession>.toml` - This file contains the configuration related to each profession, including rewards and experience gained.

## Permissions Configuration

```toml title="permissions.toml"
[permissions]
	[permissions.command]
		cobbleskills = "NONE"
		cobbleskills_reset = "NONE"
		cobbleskills_reset_self = "NONE"
		cobbleskills_reset_player = "MULTIPLAYER_MANAGEMENT"
		cobbleskills_reset_all = "ALL_COMMANDS"
		cobbleskills_leaderboard = "NONE"
		cobbleskills_profile = "NONE"
		cobbleskills_profession = "NONE"
		cobbleskills_admin = "ALL_COMMANDS"
		cobbleskills_admin_add_exp = "ALL_COMMANDS"
		cobbleskills_admin_set_level = "ALL_COMMANDS"
		cobbleskills_admin_reload = "ALL_COMMANDS"
	[permissions.gui]
		main_menu = "NONE"
		leaderboard = "NONE"
		profile = "NONE"
		profile_other = "NONE"

```

### Permissions Configuration

Allowed Values:
- `NONE` - No one can use this command.
- `SPAWN_PROTECTION_BYPASS` - Only players with spawn protection bypass can use this command.
- `CHEAT_COMMANDS_AND_COMMAND_BLOCKS` - Only players with cheat commands and command blocks can use this command.
- `MULTIPLAYER_MANAGEMENT` - Only players with multiplayer management permissions can use this command.
- `ALL_COMMANDS` - All players can use this command.

- Default: `NONE`

- Default: `NONE`

- Type: `enum`
- Default: `NONE`

## Server Configuration

```toml title="server.toml"
#Server configuration for Cobblemon Skills
[server]
	#Maximum level for all professions
	# Default: 100
	# Range: > 1
	professionMaxLevel = 100
	#Base experience required for each level
	# Default: 1020
	# Range: > 1
	professionBaseExpPerLevel = 1020
	#Multiplier for experience required per level
	# Default: 20
	# Range: > 1
	professionExpLevelMultiplier = 20
```

### professionMaxLevel

The maximum level for all professions.

- Type: `integer`
- Default: `100`
- Range: `> 1`

### professionBaseExpPerLevel

The base experience required for each level.

- Type: `integer`
- Default: `1020`
- Range: `> 1`

### professionExpLevelMultiplier

The multiplier for experience required per level.

- Type: `integer`
- Default: `20`
- Range: `> 1`

## Text Configuration

The text configuration file `text.toml` contains all the messages and text displayed by the Cobblemon Skills mod.

```toml title="text.toml"
#Text Configuration
[text]
	#The text parser to use for parsing text in the mod.
	#Allowed Values: VANILLA, EMBERS, ADVENTURE
	text_parser = "VANILLA"

	#GUI Configuration
	[text.gui]

		#Messages displayed in the GUI
		[text.gui.messages]
			#The message displayed when a reward is locked and cannot be redeemed.
			gui_messages_rewardLocked = "You have not unlocked this reward yet. Level up your %profession% profession to unlock it."
			#The message displayed when a reward has already been redeemed.
			gui_messages_rewardRedeemed = "You have successfully redeemed the rewards for %tier% in %profession%."

		#Buttons displayed in the GUI
		[text.gui.buttons]
			#The text displayed on the back button in the GUI.
			gui_buttons_backButton = "Back"
			#The text displayed on the next page button in the GUI.
			gui_buttons_navigationNext = "Next"
			#The text displayed on the previous page button in the GUI.
			gui_buttons_navigationPrevious = "Previous"

		[text.gui.leaderboard]
			#The title displayed on the leaderboard GUI.
			gui_leaderboard_title = "Cobblemon Skills Leaderboard"
			#The format for displaying the rank of a player on the leaderboard.
			gui_leaderboard_rank = "%rank%. %player%"
			#The lore displayed on the leaderboard GUI.
			gui_leaderboard_lore = ["Highest Profession Level: %highestLevel%", "Top Profession: %topProfession%"]

		#Main Menu Configuration
		[text.gui.mainMenu]
			#The title displayed on the main menu GUI.
			gui_mainMenu_title = "Cobblemon Skills"
			#The text displayed on the 'Your Profile' button in the main menu GUI.
			gui_mainMenu_yourProfileButton = "Your Profile"
			#The lore displayed on the 'Your Profile' button in the main menu GUI.
			gui_mainMenu_yourProfileButtonLore = ["View your profession progress", "and unlock status"]
			#The text displayed on the 'Leaderboard' button in the main menu GUI.
			gui_mainMenu_leaderboardButton = "Leaderboard"
			#The lore displayed on the 'Leaderboard' button in the main menu GUI.
			gui_mainMenu_leaderboardButtonLore = ["See the strongest players", "in the server"]

		#Player Profile Configuration
		[text.gui.playerProfile]
			#The title displayed on the player profile GUI.
			gui_playerProfile_title = "%player%'s Profile"
			#The lore displayed on the player profile GUI.
			gui_playerProfile_lore = ["Level: %level%", "Experience: %experience%/%nextLevelExp%"]

		#Profession Entry Configuration
		[text.gui.professionEntry]
			#The title displayed on the profession entry GUI.
			gui_professionEntry_title = "%player% - %profession% | Lvl %level%"
			#The text displayed for a redeemed reward in the profession entry GUI.
			gui_professionEntry_status_redeemed = "Redeemed"
			#The text displayed for a ready-to-redeem reward in the profession entry GUI.
			gui_professionEntry_status_ready = "Ready"
			#The text displayed for a locked reward in the profession entry GUI.
			gui_professionEntry_status_locked = "Locked"
			#The lore displayed on the profession entry GUI when viewing your own profile.
			gui_professionEntry_viewingOwnProfileLore = ["Requirement: %levelRequirement%", "Status: %status%", "Reward Count: %rewardCount%"]
			#The lore displayed on the profession entry GUI when viewing another player's profile.
			gui_professionEntry_viewingOtherProfileLore = ["Requirement: %levelRequirement%"]
			#The text displayed when a profession has no rewards configured.
			gui_professionEntry_noRewardsConfigured = "No rewards configured."
			#The lore displayed when a profession has no rewards configured.
			gui_professionEntry_noRewardsConfiguredLore = ["This profession currently has no rewards configured.", "Please ask an Admin to add some."]

	#Command Messages
	[text.commands]
		#The message displayed when experience is successfully added to a player.
		commands_addExpSuccess = "Added %amount% experience to player %player% for profession %profession%. Levels gained: %levelsGained%"
		#The message displayed to the command source when a player's level is successfully set.
		commands_setLevelSourceSuccess = "Set level of player %player% for profession %profession% to %level%"
		#The message displayed to the target player when their level is successfully set by an administrator.
		commands_setLevelTargetSuccess = "Your level for profession %profession% has been set to %level% by an administrator."
		#The message displayed when the configuration is successfully reloaded.
		commands_reloadSuccess = "Cobblemon Skills configuration reloaded successfully."
		#The message displayed when a player's data is successfully reset.
		commands_reset_selfSuccess = "Your Cobblemon Skills data has been reset."
		#The message displayed when a player's data is attempted to be reset but no data exists.
		commands_reset_selfNoData = "No Cobblemon Skills data found for your player profile."
		#The message displayed when a player's data is successfully reset by an administrator.
		commands_reset_playerSuccess = "Cobblemon Skills data for player %target% has been reset."
		#The message displayed to the target player when their data is successfully reset by an administrator.
		commands_reset_playerSuccessTarget = "Your Cobblemon Skills data has been reset by an administrator."
		#The message displayed when a player's data is attempted to be reset by an administrator but no data exists.
		commands_reset_playerNoData = "No Cobblemon Skills data found for player %target%."
		#The message displayed when all players' data is successfully reset by an administrator.

		reward_levelUp_subTitle = "&eYou have reached level %level% in %profession%!"
		#The message displayed when a player gains experience in a profession.
		reward_experienceProgress_chatMessage = "%profession% +%experience% XP | %nextLevelExperience%"
		#The message displayed when a player has maxed out their level in a profession.
		reward_experienceProgress_maxed = "Lvl %d (Max)"
		#The message displayed when a player is progressing towards the next level in a profession.
		reward_experienceProgress_progress = "Lvl %d | %.0f/%d"

	[text.errors]
		#The error message displayed when a menu fails to open.
		errors_menuError = "An error occurred while trying to open the Cobblemon Skills menu. Please contact an administrator."
		#The error message displayed when adding experience fails.
		errors_addExpError = "An error occurred while trying to add experience to the player. Please contact an administrator."
		#The error message displayed when setting a level fails.
		errors_setLevelError = "An error occurred while trying to set the level for the player. Please contact an administrator."
		#The error message displayed when setting a level exceeds the maximum allowed level.
		errors_setLevelExceedMaxLevel = "The specified level exceeds the maximum allowed level of %maxLevel%."
		#The error message displayed when reloading the configuration fails.
		errors_reloadError = "An error occurred while trying to reload the configuration. Please contact an administrator."
		#The error message displayed when resetting a player's data fails.
		errors_reset_selfError = "An error occurred while trying to reset your data. Please contact an administrator."
```

## Professions Configuration

Each profession has its own configuration file located in the `professions` directory. The configuration files are named after the profession, for example, `archeology.toml`, `botany.toml`, etc.

Below is an example configuration for the Archeology profession:

```toml title="professions/archeology.toml"
#Name of the profession
professionName = "Archeology"

	#Base experience gained from reviving a fossil

	# Range: 0.0 ~ 1.7976931348623157E308

	# Default: 400.0
	# Range: 0.0 ~ 1.7976931348623157E308
	fossilRevivalShinyBonusXp = 400.0

	# Default: 400
	# Range: > 0
	oreBlockXp = 400
	#Experience gained from mining a deepslate ore block
	# Default: 500
	# Range: > 0
	deepslateOreBlockXp = 500
	#Experience gained from mining a miscellaneous ore block
	# Default: 300
	# Range: > 0
	miscOreBlockXp = 300
	#Experience gained from mining a small tumblestone cluster
	# Default: 100
	# Range: > 0
	tumblestoneClusterSmallXp = 100
	#Experience gained from mining a medium tumblestone cluster
	# Default: 200
	# Range: > 0
	tumblestoneClusterMediumXp = 200

	# Default: 300
	# Range: > 0

	# Range: > 0
	tumblestoneClusterFullXp = 400
	#Experience gained from mining a type cluster
	# Default: 500
	# Range: > 0
	typeClusterXp = 500
	#Experience gained from mining a relic coin sack
	# Default: 600
	# Range: > 0
	relicCoinSackXp = 600
	#Experience gained from mining a relic coin pouch
	# Default: 700
	# Range: > 0
	relicCoinPouchXp = 700
	#Experience gained from mining a common archeology item
	# Default: 200
	# Range: > 0
	commonItemXp = 200
	#Experience gained from mining an uncommon archeology item
	# Default: 400
	# Range: > 0
	uncommonItemXp = 400
	#Experience gained from mining a rare archeology item
	# Default: 600
	# Range: > 0
	rareItemXp = 600

#Archeology Rewards Settings
[rewards]
	#Whether extra drops are randomly applied to block breaking rewards in archeology profession
	randomExtraDrops = true
	#The minimum level required for extra drops in archeology profession
	# Default: 10
	# Range: > 0

	displayName = "Novice"

		experience = 20
```

### Profession Configuration

Each Profession configuration file contains the following sections:

#### professionName

The name of the profession.

- Type: `string`

#### Experience Settings

Experience settings for the profession, including base experience gained from various actions and bonuses for specific conditions.

#### Rewards Settings

Rewards settings for the profession, including whether extra drops are randomly applied to block breaking rewards, the minimum level required for extra drops, and the chance for extra drops to be applied.

#### Profession Rewards Tiers

These Rewards are available from the reward claim GUI, and are unlocked when the player reaches the required level for that tier. Each tier can have multiple rewards.

There is three types of rewards that can be configured for each profession: `EXPERIENCE`, `ITEM`, and `COMMAND`.

Experience rewards have the following configuration options:
- `type` - The type of reward. Must be set to `EXPERIENCE`.
- `experience` - The amount of experience to reward the player.

Item rewards have the following configuration options:
- `type` - The type of reward. Must be set to `ITEM`.
- `item` - The item to reward the player. Must be a valid Minecraft item ID.
- `amount` - The amount of the item to reward the player.

Command rewards have the following configuration options:
- `type` - The type of reward. Must be set to `COMMAND`.
- `command` - The command to execute when the player reaches the required level. 

> Note: The command will be executed as the server console, and can include the placeholder `{player}` to represent the player's username.
